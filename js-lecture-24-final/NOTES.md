Week 2 - Conditionals, loops, control flow

## Capstone Presentation

Each student presents their project. Talk through:
- What your app does
- How you structured your data
- One feature you are proud of
- One thing you would improve with more time

## Peer Code Review

Things to look for in someone else's code:
- Are variable names clear and meaningful?
- Are functions small and focused on one thing?
- Is there repeated code that could be a function?
- Are errors handled?

Give feedback to help, not to criticize.

## What is Next

- Learn more browser APIs: localStorage, Web APIs, advanced fetch
- Pick a framework: React is the most common in the industry right now
- Learn Git properly: branching, pull requests, code review workflow
- Keep building projects: it is the only way to actually get better

## Final Tip

The goal is not to memorize syntax. The goal is to learn how to break problems into smaller pieces and solve them one step at a time. Syntax you can always look up. Problem solving is the real skill.

Keep building. Keep asking questions.
