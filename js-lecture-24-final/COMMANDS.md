# Common Commands - Student Guide

## Fork the Repository

Click Fork on GitHub to create your own copy of the repo.

This lets you work on the code without changing the original.

## Clone Your Fork

git clone <your-repo-link>

Downloads your GitHub repository to your computer.

## Move Into the Project Folder

cd js-lecture-24-final

Moves your terminal into the project folder so commands work correctly.

## Install Dependencies

npm install

Installs required packages (like Jest) needed to run tests.

## Run Tests

npm test

Runs automated tests to check if your code works.

Tests failing = code needs fixing
Tests passing = task completed

## Check Git Status

git status

Shows which files you changed and what is ready to be committed.

## Add Changes

git add .

Stages all your changes so they can be committed.

## Commit Your Work

git commit -m "Completed js-lecture-24-final challenges"

Saves your changes with a message.

## Push to GitHub

git push

Uploads your code to GitHub so it is saved online.

## Typical Workflow

git clone <your-repo-link>
cd js-lecture-24-final
npm install
npm test
git add .
git commit -m "message"
git push

## Important Notes

- Run npm test often
- Commit even if all tests are not passing
- Do not edit test files
- Ask questions in the doubt session if stuck
